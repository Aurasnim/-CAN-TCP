# -CAN-TCP
Репозиторий для практики студентов МАИ по теме реализации CAN (Сенькович М3О-311Б-22) и TCP/IP(Бондаренко М3О-309Б-22) на плате STM32

Задание Сенькович:
Реализация монитора шины CAN на базе микроконтроллера STM32F207 с применением библиотеки HAL. 

Задание Бондаренко:
Реализация протокола TCP/IP (over Ethernet) на микроконтроллере STM32F207 с применением библиотеки LWIP.
